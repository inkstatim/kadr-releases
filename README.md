# Kadr — релизы

Kadr — нативное приложение для скриншотов и записи экрана на macOS: снимки области и окна, редактор с пометками,
скролл-скриншоты, OCR, запись MP4/GIF, оформление снимков. Сейчас идёт ранний доступ: все функции бесплатны.

### [⬇ Скачать Kadr для macOS](https://github.com/inkstatim/kadr-releases/releases/latest)

macOS 14 и новее, Apple Silicon и Intel. Бесплатно.

## Установка

1. Откройте `Kadr-<версия>.dmg` и перетащите **Kadr** в «Программы».
2. Запустите Kadr. Он пока не заверен Apple (это платно, сделаем позже), поэтому macOS предупредит,
   что не может проверить разработчика. Нажмите «Готово», затем:
   - **macOS 15 и новее:** «Системные настройки» → «Конфиденциальность и безопасность» → внизу
     «Kadr заблокирован…» → **«Всё равно открыть»** → подтвердите паролем.
   - **macOS 14:** правый клик по Kadr в «Программах» → «Открыть» → «Открыть».
3. Kadr появится в строке меню и проведёт по разрешениям: «Запись экрана» нужна для всех снимков,
   «Универсальный доступ» — только для скролл-скриншотов.

Обновления Kadr проверяет сам (меню → «Проверить обновления…»). Разрешения при обновлении сохраняются.

Идеи, предложения и ошибки — в Telegram [@akm_tims](https://t.me/akm_tims).

## Для разработчика

`appcast.json` — манифест обновлений: Kadr раз в сутки и по «Проверить обновления…» читает его
с `raw.githubusercontent.com` и предлагает скачать новую версию, если `build` больше установленного.
Ссылка `url` должна вести в этот репозиторий — другие адреса приложение не откроет.

Выпуск версии: DMG из `scripts/release.sh` → новый релиз здесь (тег `v<версия>`, DMG во вложении),
затем поднять `version`, `build`, `url` (ссылка на DMG релиза) и `notes` в `appcast.json`.
